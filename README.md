# local_suap

O `local_suap` é um plugin local do Moodle responsável pelo núcleo da integração entre o AVA (Ambiente Virtual de Aprendizagem) e o SUAP (Sistema Unificado de Administração Pública), realizando a sincronização bidirecional de dados acadêmicos.

`local_suap` is a Moodle local plugin responsible for the core integration between the VLE (Virtual Learning Environment) and SUAP (Unified Public Administration System), performing bidirectional synchronization of academic data.
