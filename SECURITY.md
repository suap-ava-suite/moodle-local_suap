# Security Policy

## Supported Versions

Only the latest version of `local_suap` on the default branch is currently supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `local_suap`, please do NOT create a public issue. Instead, report it directly to the project maintainers.

### Reporting Process
1. Email your report to the maintainer: **Kelson Medeiros** (`kelsoncm@gmail.com`).
2. Alternatively, create a [Private Vulnerability Report](https://github.com/suap-ava-suite/moodle-local_suap/security/advisories/new) if enabled on GitHub.

### What to Include in Your Report
- A detailed description of the vulnerability.
- Steps to reproduce the issue or a proof-of-concept (PoC).
- Any potential impact or vectors of exploitation.

### Response Timeframe
- **Initial Response**: Within 48 hours acknowledging receipt of your report.
- **Status Update**: Periodic updates regarding investigation and resolution progress.
- **Fix Release**: Security patches will be merged and tagged as soon as verified.

Thank you for helping keep `local_suap` and its community safe!
